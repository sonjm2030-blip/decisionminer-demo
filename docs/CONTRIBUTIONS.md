# 기여 기록과 근거

공모전 자료를 통해 확인되는 사실과 계획상 역할을 구분합니다.

| 내용 | 근거 | 확인 범위 |
| --- | --- | --- |
| 팀 세종대왕, 팀 대표 손종명, 팀원 박세하 | 1차 참가신청서 및 HWPX 신청서 | 팀 구성 확인 |
| 프로젝트 Owner가 주 작업을 수행하고 B가 법리·근거 검수를 담당 | DecisionMiner_PRD_v2.md, 2026-04-27 | 당시 계획·역할 문서. ‘90%+’는 문서의 자기기록이며 측정된 기여율로 사용하지 않음 |

| 손종명이 최종 발표자 | 최종 발표자료 첫 페이지 | 발표자 확인 |
| Claude Code 등을 활용한 코드 구현 | PRD의 도구·사용처 항목과 구현 산출물 | AI 코딩 도구 활용을 명시. 전 코드를 독립 작성했다고 기술하지 않음 |

GitHub의 프로젝트 설명은 팀 프로젝트로 기술합니다. 팀원의 실명과 검수자 코드 B를 직접 연결하는 명시적 문서, 변호사 자격 여부, 파일별 독립 작성 비율은 위 자료만으로 확정하지 않습니다. ‘법학 전공 검수’와 ‘변호사 등 법률 전문가 검증 완료’를 혼용하지 않습니다.

손종명의 경험을 소개할 때는 팀 대표·발표, 프로젝트 기획, 데이터 구조와 품질관리 흐름 설계, AI 코딩 도구를 활용한 구현·운영이라는 범위로 설명하되, 계획서상 역할과 실제 산출물의 구분을 유지합니다. 기존 검수 100건은 본인이 혼자 법적 정답을 확정한 성과로 표현하지 않습니다.

개인 연락처·서명·동의서·상금 관련 서류는 저장소에 새로 복사하지 않았습니다. 검수·팀 구성의 근거만 기록합니다.
