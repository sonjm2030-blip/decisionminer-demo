# 기준 버전과 수치 정의

이 문서는 공모전 당시 결과를 동결하기 위한 기록입니다. 데이터·라벨을 연구 결과에 맞춰 고치지 않고, 실제 파일을 연결해 현재 재현되는 수치를 남깁니다.

## 기준 입력

- 최종 제출 설계서: `releases/competition_final.xlsx`.
- 기존 100건 검수 원본: `releases/reviewer_100.xlsx`.
- 원 QA와 구 자동판정: `qa_evaluated_990.csv`, `qc_result_990_v2.csv`.
- 최종 정적 라벨: `static_labels_990.json`. 최종 설계서 17열의 명시된 신뢰등급과 990개 ID 모두 일치합니다.
- 입력 해시와 혼동행렬: [baseline_metrics.json](baseline_metrics.json).

## 규모와 분류

인벤토리 500건 중 22건을 선정했습니다. QA는 사건당 45건, 총 990건이며 요약·사실관계·분류·추론 메타데이터가 각각 22건입니다. QA+메타데이터 1,078건은 서로 다른 데이터 유형을 합친 산출물 수입니다.

최종 정적 라벨 분포는 적합 195, 검토 768, 부적합 27입니다. 구 자동검수 CSV는 Gold 148, 보정필요 829, 탈락 13으로, 서로 다른 판정 버전입니다. 라이브 grounding CSV도 별도 경로이므로 이 분포들과 혼용하지 않습니다.

## 100건 검수의 세 계산

검수 원본의 100개 판정을 설계서의 약칭→원 QA ID 대응표로 연결했습니다. 원 검수자 판정은 OK·보정 필요·환각입니다. 기존 100건을 기준 정밀화에 사용했으므로 독립적인 일반화 성능으로 해석하지 않습니다.

| 자동판정 출처 | 세 범주 정확 일치 | 역사적 비대칭 방향 계산 | 사용가능/부적합 이진 일치 |
| --- | ---: | ---: | ---: |
| 구 CSV `qc_result_990_v2.csv` | 55/100 | 88/100 | 99/100 |
| 최종 정적 라벨·최종 설계서 17열 | 55/100 | 적용하지 않음 | 98/100 |

- 세 범주 정확 일치: Gold/적합↔OK, 보정필요/검토↔보정 필요, 탈락/부적합↔환각.
- 역사적 방향 계산: 기존 패치 스크립트의 허용 쌍을 그대로 재현합니다. 자동 보정필요↔사람 환각도 허용하는 등 이진 일치와 정의가 다릅니다.
- 이진 일치: Gold·보정필요 또는 적합·검토를 ‘사용가능’, 탈락·부적합을 ‘부적합’으로 합칩니다. 사람의 OK·보정 필요도 ‘사용가능’, 환각은 ‘부적합’으로 합칩니다.

최종 라벨의 이진 혼동행렬은 자동 사용가능·사람 사용가능 97건, 자동 사용가능·사람 환각 1건, 자동 부적합·사람 사용가능 1건, 양쪽 부적합 1건입니다. 구 CSV는 각각 98·1·0·1건입니다.

최종 제출 문서에는 ‘88%→99%, E5 주의 강등’이라는 설명이 남아 있습니다. 그러나 구 CSV 하나로도 정의를 바꾸면 88과 99가 모두 재현됩니다. 따라서 이 기준 버전에서는 이를 동일 지표의 성능 향상으로 주장하지 않습니다. 최종 설계서의 검수표도 구 판정을 유지하고 있어, 최종 라벨과의 연결 결과를 별도로 보고합니다.

`qa_corrections_100.csv`는 이름과 달리 63행의 보정 기록입니다. 전체 100건 검수 원본 대신 사용할 수 없습니다.

## 기준 버전에서 정리한 것

- 기존 생산·검수 코드와 아직 커밋되지 않았던 내보내기 코드·결과를 보존합니다.
- 2차 웹 시연 코드와 최종 설계서·검수 원본을 출처 해시와 함께 추가합니다.
- 잘린 한글 폴더에 분산돼 있던 sidecar JSON 10개의 출처와 이전 커밋의 바이트가 동일함을 확인했습니다. 기준 스냅샷에는 완전한 사건명 경로를 유지하며, 원본 복사본도 로컬에 보존합니다.
- 백업·로컬 설정·실행 로그를 신규 기준 커밋 대상에서 분리합니다.
- 모델·프롬프트·판정 규칙의 연구적 개선이나 데이터 재생성은 하지 않습니다.

## 재현 명령

```bash
python -m pip install -r requirements-audit.txt
python scripts/audit_baseline.py
python scripts/audit_baseline.py --output /tmp/decisionminer-audit.json
```

이 명령은 저장 자료를 읽습니다. API·다운로드·모델 학습을 실행하지 않습니다. 결과를 저장한 보고서와 비교하려면 현재 입력 해시까지 확인하세요. 실제 PDF 재생성은 외부 원문과 인벤토리 경로, 모델 접근권한이 추가로 필요합니다.
