# 기준 버전 이후의 연구 계획

공모전 결과의 기준점은 `74135ad`와 `baseline/competition-2026-11-01`입니다. 후속 작업은 연구 브랜치에서 진행합니다.

1. 기존 ID·문항·답변·근거·라벨을 고정하고 검수표와 최종 라벨의 계보를 정리합니다.
2. 법률 전문가 재검수 100건의 표집·자격·검수 지침·눈가림 조건을 정합니다. 기존 교정 표본과의 중복을 기록하고, 가능하면 일부 문항에 복수 검수자를 배치합니다.
3. 연구 A: 규칙 기반 기준점에 복수 LLM Judge·루브릭을 추가해 오류 유형, 세 범주 일치도, Cohen’s κ 등을 비교합니다.
4. 연구 B: 규칙 검사·LLM 검토·사람 검수의 단계별 효과와 검수 비용을 비교합니다.
5. 동일 정의·동일 표본으로 비교하고, 개선에 사용하지 않은 평가 문항·사건을 따로 둡니다.
6. 실험 설정·모델 버전·비용·한계를 결과와 함께 기록합니다.

먼저 최종 라벨의 계보와 독립 평가 설계를 확정합니다. 88·99·98처럼 정의나 라벨 버전이 다른 수치를 한 줄의 성능 향상으로 묶지 않습니다.

2026-11-01 후속 작업: [100건 재검수 설계 및 버전 감사](../research/review100/README.md)를 추가했습니다. 기존 100건과 최종 제출본은 일부 질문·답변 텍스트가 다르므로, 과거 사람 판정을 최종본의 유효성 검증으로 재사용하지 않습니다. 새 검수는 최종본 입력을 고정해 진행하며 현재는 지침과 빈 양식을 준비한 단계입니다.

기존 기록 분석 단계: 사용자 요청에 따라 재검수 준비는 여기까지 보존하고 [기존 검수 기록 분석](../research/legacy_review/README.md)으로 전환했습니다. 기존 100건 기록·보정안을 점검하고 공통 6항목이 일치하는 79건에 기존 규칙 두 모드를 재실행했습니다. 이 사후 분석 단계에서는 추가 LLM 호출 없이 논문 본문의 방법과 대조하고 두 연구 질문을 정리했습니다.

이후 [첫 LLM Judge 비교](../research/judge/README.md)를 실제로 실행했습니다. 같은 79개 문항과 원문 발췌에 단순 지시·공통 항목별 지시를 적용해 158개 응답을 보존했습니다. 항목별 기준의 우위는 확인하지 못했으며, 인용·출력 실패와 검토량 증가를 함께 보고했습니다. 이 단계도 개발 표본 비교이며 신규 전문가 검수·독립 시험세트·학습 효용 실험은 수행하지 않았습니다. 다음 개선은 인용 출력의 신뢰성과 근거 부족의 구분을 우선합니다.
