# B 검수 가이드 v1

> DecisionMiner — 법리·근거 검수 담당자(B)용 작업 지침서

---

## 0. B의 역할

법학 전공자로서 5단 분해 결과의 **법리·근거 정확성** 검수.

- 일일 평균 **3시간**, Day 3~8 (6일 분산)
- 목표: 총 **198건** 검수 완료 (Tier 2 이상)

### 작업 파일

- **파일**: `05_xlsx/학습데이터_설계서_구조_v3.4.xlsx`
- **시트**: `법리_검수` (11컬럼)
- 사건유형·페르소나·적용 법령·적용 조문은 자동 입력 → B가 6번 이후 컬럼 직접 작성

---

## 1. 11컬럼 의미 + 채우는 법

| # | 컬럼 | 의미 |
|---|---|---|
| 1 | QA_ID | 5단 분해 Q&A의 ID |
| 2 | 페르소나 | 일반국민 / 기업 컴플라이언스 담당자 / 논문 준비 학생 |
| 3 | 사건유형 | 담합 / 하도급 / … |
| 4 | 적용 법령 | 화이트리스트 7개 중 |
| 5 | 적용 조문 | 제N조 |
| 6 | **판단 요건** | 위반으로 판단한 핵심 요건 **(일반론)** |
| 7 | **본건 적용 이유** | 이 사건이 위 요건을 충족하는 이유 **(본 사건 사실)** |
| 8 | 검수자 평가 | OK / 보정 필요 / 환각 |
| 9 | 보정안 | 보정 필요·환각 시 수정안 작성 |
| 10 | 신뢰도 | 1~5점 |
| 11 | 메모 | 자유 기재 |

> ⚠️ **핵심 주의**: **6번(판단 요건)은 일반론**, **7번(본건 적용 이유)은 본 사건 사실**. 두 컬럼 혼동 금지.

---

## 2. 채우는 우선순위

1. **QA_ID 복사** → 페르소나·사건유형·적용 법령·적용 조문은 Step 2 결과 그대로 자동 입력
2. **판단 요건·본건 적용 이유 작성** ← B의 핵심 작업
3. **검수자 평가** 선택 (OK / 보정 필요 / 환각)
4. 신뢰도(1~5) + 메모 입력

---

## 3. 환각 발견 시

아래 4가지 중 하나라도 해당하면 **"환각"** 평가 + 보정안 작성 필수.

| 환각 유형 | 판단 기준 |
|---|---|
| 법령 오인용 | 화이트리스트 7개 이외 법령 인용 |
| 조문 번호 오류 | 조문 번호 틀림 |
| 5요소 누락 | Step 1 사실관계 요소 비어있음 |
| 페르소나 톤 어긋남 | 대상 페르소나에 맞지 않는 어조·용어 |

→ 컬럼 8 = `환각`, 컬럼 9에 **수정안 직접 작성**

---

| # | 법령명 |
|---|---|
| 1 | 공정거래법 |
| 2 | 하도급법 |
