# B 검수 가이드 v2

> DecisionMiner — 법리·근거 검수 담당자(B)용 **실행 설명서**
> 시트 구조: 법리_검수 탭 13컬럼 (A~M열)

---

## 0. 왜 하는 건지

AI가 공정위 의결서 270개 Q&A를 자동 생성했다.
AI가 법령 조문을 틀리게 인용하거나 잘못된 법리를 쓰는 경우가 있다.
B가 법학 전공자로서 이걸 잡아주는 역할이다.

> **공모전 평가 차별점**: "AI 생성 데이터를 법학 전공자가 검수했다"

---

## 1. 파일 열기

- **파일**: `05_xlsx/학습데이터_설계서_구조_v3.4.xlsx`
- **시트**: `법리_검수` 탭
- **오늘 작업 행**: 2행 ~ 9행 (총 8건)
  - 2~5행: `QA-쿠팡-001` ~ `QA-쿠팡-004`
  - 6~9행: `QA-네이버-001` ~ `QA-네이버-004`

> 처음이라 8건만. 방향 맞으면 다음부터 하루 20~30건.

---

## 2. 건드리지 마라 (A~E열, 자동 입력)

| 열 | 컬럼명 | 예시 (QA-네이버-001) |
|---|---|---|
| A | QA_ID | `QA-네이버-001` |
| B | 페르소나 | `일반국민` |
| C | 사건유형 | `표시광고` |
| D | 적용 법령 | `표시광고법` |
| E | 적용 조문 | `제3조 제1항 제1호 및 제2호` |

> A~E열에 오류가 보여도 직접 수정 금지. J열(검수자 평가)·M열(메모)에 표시만.

---

## 3. 참고만 해라 (F~G열, 연파랑 #E8F4FD)

| 열 | 컬럼명 | 의미 |
|---|---|---|
| F | **질문** | AI가 생성한 질문 |
| G | **답변** | AI가 생성한 답변 ← **이게 법적으로 맞는지 검수하는 대상** |

> F·G열은 **읽기 전용** 참고용이다. 수정 금지. G열 답변이 검수 대상.

---

## 4. B가 채워라 (H~M열, 연노랑 #FFF2CC)

각 행마다 H~M 6셀 채워라.

### H열 — 판단 요건

- G열 답변이 근거로 삼은 **법리 요건을 일반론**으로 써라.
- 이 사건 사실 언급 X. 법이 일반적으로 요구하는 조건만.
- 번호 매기기(①②③) 권장.

**예시**:
```
① 사업자가 ② 소비자를 기만할 우려 있는 표시를 ③ 할 것
```

### I열 — 본건 적용 이유

- 이 사건이 왜 H열 요건에 해당하는지 **구체적**으로 써라.
- 사건명·행위·결과 박음.

**예시**:
```
네이버가 검색광고를 일반 검색결과처럼 표시해
소비자가 광고임을 구분 불가
```

### J열 — 검수자 평가

- G열 답변 보고 **셋 중 하나만** 입력. 다른 텍스트 금지.
  - `OK`
  - `보정 필요`
  - `환각`

### K열 — 보정안

- J=OK면 **공백**.
- J=`보정 필요` 또는 `환각`이면 **수정안 직접 작성**.

### L열 — 신뢰도

- **숫자만** (1~5). 단위·텍스트 금지.

| 점수 | 기준 |
|---|---|
| **5** | 완벽 |
| **4** | 경미한 보정 |
| **3** | 오류 보정 필요 |
| **2** | 환각 |
| **1** | 전면 재작성 |

### M열 — 메모

- 자유 기재. 없으면 공백.

---

## 5. H열 vs I열 — **절대 혼동 금지** ⚠️

가장 많이 발생하는 실수다.

| 열 | 역할 |
|---|---|
| **H (판단 요건)** | **법이 뭐라고 하는지** (일반론, 이 사건 언급 X) |
| **I (본건 적용 이유)** | **이 사건이 왜 그 법에 걸리는지** (이 사건 구체 사실) |

### 틀린 예
```
H열: 네이버가 검색광고를 일반 결과처럼 표시한 행위
```
→ "네이버가 ~한 행위"는 본건 사실이므로 **I열로 옮겨라**.

### 맞는 예
```
H열: ① 사업자가 ② 소비자를 기만할 우려 있는 표시를 ③ 할 것
I열: 네이버가 검색광고를 일반 결과처럼 표시해 소비자가 광고임을 구분 불가
```

> H는 **추상**, I는 **구체**. H는 다른 사건에도 재사용 가능해야 한다.

---

## 6. 환각 판단 (J=`환각` 쓰는 경우)

아래 **4가지 중 1개라도** 해당하면 J=`환각`, K에 보정안 작성.

### ① D열 법령이 화이트리스트 7개 외

- 공정거래법
- 하도급법
- 표시광고법
- 가맹사업법
- 대규모유통업법
- 전자상거래법
- 약관규제법

> 약칭(예: "전자상거래소비자보호법") 인용은 OK. 비공식 명칭·폐지 법령은 환각.

### ② E열 조문 번호 틀림

- 의결서 실제 조문과 다르면 환각.
- K열에 정확한 조문 명시.

### ③ G열 답변에 5요소 중 빠진 것 있음

주체 / 상대방 / 시장 / 행위 / 결과 — 이 5개 중 빠지면 환각.

### ④ G열 답변 어조가 B열 페르소나와 안 맞음

| 페르소나 | 톤 |
|---|---|
| **일반국민** | 쉬운 말 |
| **기업 컴플라이언스 담당자** | 실무 용어 |
| **논문 준비 학생** | 학술 용어 |

**페르소나별 금지어** (이게 답변에 있으면 톤 어긋남):

| 페르소나 | 금지어 |
|---|---|
| **일반국민** | 비례성·구성요건·포섭·법리적·선행 연구·학술 표현 |
| **기업 컴플라이언스 담당자** | 비례성·선례·함의·후속 연구·`~네요`·당했어요·엄청 |
| **논문 준비 학생** | `~네요`·엄청·되게·생활 밀착 비유·`당사`·`자사`·`체크리스트` |

## 7. 작업 흐름 (행 1개당 5~7분)

각 행 처리 시 아래 순서.

- [ ] A~E열 자동 입력 1번 읽기
- [ ] F열 질문 읽기
- [ ] **G열 답변 읽기** ← 검수 대상
- [ ] D열 법령이 화이트리스트 7개 안에 있는지 확인
- [ ] E열 조문이 의결서 실제 조문과 일치하는지 확인
- [ ] H열에 **일반 요건** ①②③ 작성
- [ ] I열에 **본건 사실** 매핑 작성 (5요소 박음)
- [ ] 6절 환각 4유형 중 해당 사항 점검
- [ ] J열에 `OK` / `보정 필요` / `환각` 1개 선택
- [ ] J가 OK 아니면 K열에 보정안 작성
- [ ] L열에 신뢰도 1~5 숫자
- [ ] M열에 메모 (선택)
- [ ] 다음 행으로
