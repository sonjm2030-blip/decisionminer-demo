````
# 5요소 정의

## 1. 피심인 (Defendant)
- 의결서 "주문" 섹션의 피심인 명시
- `metadata.피심인정보[*].피심인명` 1순위
- 단일: 문자열 (예: `"에스피피조선(주)"`)
- 복수: 배열 (예: `["A건설(주)", "B건설(주)", "C건설(주)"]`)

## 2. 시정명령 (Corrective Order)
- 시정명령 내용을 한 문장으로 요약
- 의결서 "주문" 1항 ~ N항 중 시정명령 항 박음
- 시정명령 없으면 `"정보 없음"` 명시 강제 (빈 문자열 ❌)

## 3. 과징금 (Surcharge Imposition)
- 과징금 부과 사실 (텍스트)
- 예: `"과징금 4억 8천만 원 부과"` / `"과징금 미부과"` / `"과징금 면제"`
- 과징금 없으면 `"미부과"` 명시

## 4. 과징금액 (Surcharge Amount, 정수 강제)
- **원 단위 정수** (콤마·"원" ❌)
- "주문" 섹션의 과징금 액수
- 미부과·면제 → `0`
- 단위 변환:
  - "4억 8천만 원" → `480000000`
  - "1억 2,500만 원" → `125000000`
  - "5,000,000원" → `5000000`

### 복수 피심인 합산
- 단일: 그대로 정수
- 복수: **모든 피심인의 과징금 합계** (총합)
- 개별 금액은 `피심인별_상세` 배열에 박음

## 5. 근거조문 (Legal Basis Article)
- Step 2의 `법령` + `조문` 직접 매핑
- 형식: `"<법령 약칭> <조문>"`
- 예: `"하도급법 제11조 제1항"`, `"공정거래법 제40조 제1항"`
- Step 2 정합 강제. 충돌 시 의결서 본문 재확인

```

배열 예시:
- `["시정명령", "과징금"]`
- `["시정명령", "과징금", "고발"]`
- `["경고"]`
- `["시정명령"]` (과징금 없을 때 — 과징금액 = 0)

## 기간

- 의결서 "주문"에 박힌 시정명령 이행 기간 또는 행위 금지 기간

- 예: `"이 명령을 받은 날부터 60일 이내"`, `"3년간 행위 금지"`
- 명시 안 됨 → `"정보 없음"`

- 복수 피심인: **반드시 박음**. 각 피심인별 처분 분리.

# 핵심 원칙

## 원칙 1 — "주문" 섹션 전용
- 본문 "이유"·"인정사실" 섹션 ❌
- 본문 산정표가 매력적이어도 "주문" 최종 금액만

## 원칙 2 — 추측 금지
- 의결서에 박힌 것만
- 모르는 값 → **`"정보 없음"` 또는 `0` 명시 강제** (빈 문자열 ❌)

## 원칙 3 — 단위·형식 정확
- `과징금액`: 정수 (콤마·단위 ❌)
- `처분유형`: 5종 enum 외 ❌
- `기간`: 의결서 표현 그대로 (자연스러운 정규화 OK)

## 원칙 4 — Step 1·2와 정합
- `피심인` ⊆ `facts.facts_structured.당사자` (피심인 역할)
- `처분유형` ⊇ `legal.classification_tags.처분_유형` (Step 2가 부분집합)
- `근거조문` = `legal.법령` + `legal.조문` 합성

## 원칙 5 — 금액 0원 처리 (시정명령만)
- 시정명령만 있고 과징금 없으면 → `과징금: "미부과"`, `과징금액: 0`
- 빈 값·null ❌. **반드시 `0` 박음**

## 원칙 6 — JSON 스키마 강제
- 키 누락·추가 ❌
- 정수 필드는 정수, 배열은 배열

# 복수 피심인 처리

담합·사업자단체 사건은 거의 모두 복수 피심인.

### 단일 피심인
- `피심인`: 문자열
- `피심인별_상세` 생략 또는 `[]`

### 복수 피심인
- `피심인`: 배열
- `처분유형`: 모든 피심인 처분의 **합집합**
- `과징금액`: 모든 피심인 과징금의 **총합**
- `기간`: 동일하면 그대로, 다르면 가장 긴 기간 또는 `"피심인별 상이"`
- `피심인별_상세`: **반드시 박음**

```json

```
주     문

1. 피심인 에스피피조선(주)는 다음과 같이 시정하라.
   가. 피심인은 향후 정당한 사유 없이 수급사업자에게 결정한
       하도급대금을 감액하는 행위를 하여서는 아니된다.
   나. 피심인은 이 명령을 받은 날부터 60일 이내에
       위 가. 항의 명령을 받은 사실을 ... 통지하여야 한다.

2. 피심인 에스피피조선(주)에 과징금 480,000,000원을 부과한다.
```

# 자가 검증 룰

- [ ] **5요소(피심인·시정명령·과징금·과징금액·근거조문) 모두 채워짐** — 빈 문자열 0건
- [ ] `과징금액` 타입 **정수** (`int`, 콤마·단위 ❌)
- [ ] `과징금액` ≥ 0 (음수 ❌)
- [ ] **시정명령만 있고 과징금 없을 시 `과징금: "미부과"`, `과징금액: 0`** (빈 값·null ❌)
- [ ] **`처분유형` 모든 값 ∈ 5종 enum** {시정명령, 과징금, 고발, 경고, 과태료}
- [ ] `처분유형` 배열 길이 ≥ 1
- [ ] `근거조문` = `legal.법령` + `legal.조문` 정합
- [ ] **`legal.classification_tags.처분_유형` ⊆ `처분유형`** (Step 2 정합)
- [ ] 복수 피심인 시 `피심인별_상세` 박힘
- [ ] `피심인별_상세[*].과징금액` 합 == 최상위 `과징금액` (총합 검증)
- [ ] 모든 수치·기간이 의결서 "주문" 섹션 추출 (창작 0건)
- [ ] JSON 외 텍스트 0건

# 예외 처리

## 케이스 1 — 과징금 면제·미부과
- `처분유형`에 `"과징금"` 미포함
- `과징금`: `"면제"` 또는 `"미부과"`
- `과징금액`: `0`
- 복수 피심인 시 `피심인별_상세.비고`에 `"과징금 면제"` 명시

## 케이스 2 — 시정명령만 (과징금 없음)
- `처분유형`: `["시정명령"]`
- `과징금`: `"미부과"`, `과징금액`: `0`
- `기간`: 시정명령 이행 기간

## 케이스 3 — 동의의결·자진시정 종결 (5종 enum 외)
- 가장 가까운 enum 1개 (보통 `["시정명령"]`)
- `피심인별_상세.비고`에 정확한 처분명 (예: `"동의의결"`, `"자진시정 종결"`)
- `과징금액`: 동의의결안에 박힌 자진시정 비용·기금 출연액 또는 `0`

## 케이스 4 — 기각·각하
- `처분유형`: `["경고"]` (가장 가까운 enum) 또는 단일 피심인 시 `["기타"]` 박지 말고 빈 배열 회피
- `과징금액`: `0`
- `기간`: `"정보 없음"`
- `피심인별_상세.비고`: 정확한 처분명 (`"심사절차 종료"` 등)

## 케이스 5 — 일부 피심인 기각
````
