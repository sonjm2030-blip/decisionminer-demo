````
# 페르소나 3종 정의 (v2 라벨·어휘 강화)

## 1. 일반국민

| 항목 | 박음 |
|---|---|
| 정체성 | 법률 문외한, 뉴스에서 사건 접한 일반 시민 |
| 어휘 | 환불·거부·신고·받았다·당했다·어떻게·왜·이런 경우·내가 |
| 톤 마커 | `~요`·`~네요`·`~세요`·있어요·돼요 |
| ⭐ 어휘 가이드 (v2 강화) | **법 전문용어 사용 시 괄호 안에 설명 박음** (예: "과징금(벌금 같은 거예요)") |
| 답변 길이 | **80~400자** (난이도별 차등) |
| 비유·예시 | 적극 활용 (생활 밀착) |
| 금지어 | 비례성·구성요건·포섭·법리적·선행 연구·학술 표현 |
| 질문 톤 예시 | "에스피피조선이 받은 처벌이 뭐예요?" |

## 2. 기업 컴플라이언스 담당자 ⭐ (v3.4 정렬)

| 항목 | 박음 |
|---|---|
| 정체성 | 기업 법무·컴플라이언스 실무자, 자사 사업에 동일 행위 발생 시 위반 리스크 사전 점검 |
| 어휘 | 리스크·조문·요건·예방·내부통제·실무 가이드·매뉴얼·체크리스트·당사·자사·사전 점검 |
| 톤 마커 | `~합니다`·`~됩니다`·`~해야 합니다`·`~할 수 있습니다` (실무 전문 톤) |
| ⭐ 어휘 가이드 (v3.4) | **조문·요건 직접 인용 + 사전 예방 포인트 박음** ("본 사건의 핵심 위반 요건은 ...이므로 당사 거래에서는 ... 단계에서 점검 필요") |
| 답변 길이 | **150~600자** (난이도별 차등) |
| 관점 | "당사/자사 사업에서 동일 행위 발생 시 어떻게 사전 차단할지" 컴플라이언스 시점 |
| 금지어 | 비례성·선례·함의·정책적 함의·후속 연구 (논문 준비 학생 어휘) / `~네요`·당했어요·엄청 (일반국민 어휘 일부) |
| 질문 톤 예시 | "당사 하도급 거래에서 단가 조정을 단행할 경우 본 사건과 같은 위반 리스크를 어떻게 차단할 수 있습니까?" |

> **기업 컴플라이언스 담당자는 일반국민과 논문 준비 학생 사이의 실무자 페르소나**. 법리·학술 분석보다는 "당사 사업에 적용되면 어떻게 차단할지"가 핵심 관심사. 조문·요건 직접 인용 OK.

## 3. 논문 준비 학생 ⭐ (v3.4 정렬)

| 항목 | 박음 |
|---|---|
| 정체성 | 법학·경제학 대학원생/연구자, 논문·정책 보고서 자료 수집·학술 분석 |
| 어휘 | 비례성·구성요건·선례·판례·법리적·정책적·산업적·함의·시사·논거·후속 과제·비교법적 |
| 톤 마커 | 분석된다·평가된다·시사된다·인정된다·검토된다 (학술적 수동태) |
| ⭐ 어휘 가이드 (v3.4) | **법령 조문 직접 인용 + 판례·선례 참조 + 비교법적·정책적 함의 + 후속 연구 과제 박음** |
| 답변 길이 | **200~800자** (난이도별 차등) |
| 관점 | 학술적·정책적·비교법적·선례 분석, 후속 연구 과제 제시 |
| 금지어 | `~네요`·엄청·되게·생활 밀착 비유 / `당사`·`자사`·`내부통제`·`체크리스트` (실무 어휘) |
| 질문 톤 예시 | "본 사건의 처분이 조선 블록 하도급 시장에 미친 산업적·정책적 함의와 후속 정책 과제는?" |

> 논문 준비 학생은 학술 시점 — 사건을 선례로 해석하고 비교법·정책적 함의를 도출하는 페르소나. 실무 가이드(컴플라이언스 담당자)와 일상 설명(일반국민) 모두에서 분리.

# 질문유형 5종

| 유형 | 초점 | 매핑 Step 결과 | chunk_id 1순위 |
|---|---|---|---|
| `제재중심` | 어떤 처벌·처분 받았나 | sanction (Step 3) | `evidence.sanction_evidence.*` |
| `법령중심` | 왜 위법인가, 어떤 법조문 | legal (Step 2) | `evidence.legal_evidence.*` |
| `유사사례` | 비슷한 사건은 | facts + legal (1+2) | `evidence.facts_evidence.행위` |
| `통계기반` | 수치·빈도·추세 | facts.결과 + sanction (1+3) | `evidence.facts_evidence.결과` |
| `시장영향` | 산업·소비자 영향 | facts.시장·상대방 (1) | `evidence.facts_evidence.시장` |

⚠️ `유사사례`·`통계기반`은 본 의결서 1건만으로 직접 답변 어려움 → **본 사건의 사실관계 + 일반론**으로 답변 구성. 다른 사건의 구체 정보 창작 ❌.

# 난이도 3종

페르소나는 **어휘·톤**, 난이도는 **깊이·전문성**. 두 축은 직교.

## 1. 기초
- 처음 접하는 사람도 이해
- 핵심 사실 + 결과 중심
- 법조문 인용 최소

## 2. 심화
- 어느 정도 배경지식 있는 사람
- 법령·요건 명시 OK

## 3. 전문가 (난이도)
- 법률·정책 전문가 수준
- 법리 분석·선례 비교·정책적 함의

## 페르소나 × 난이도 길이 매트릭스

| 페르소나 | 기초 | 심화 | 전문가(난이도) |
|---|---|---|---|
| 일반국민 | 80~150자 | 150~250자 | 250~400자 |
| 기업 컴플라이언스 담당자 | 150~250자 | 250~400자 | 400~600자 |
| 논문 준비 학생 | 200~350자 | 350~550자 | 550~800자 |

# 핵심 원칙

## 원칙 1 — 정확히 45개 ⚠️ 최우선
- 44개·46개 ❌
- 모든 조합 (3 × 5 × 3) 각 정확히 1번

## 원칙 2 — 페르소나 톤 차별성
- 답변만 보고도 어느 페르소나인지 80%+ 식별 가능
- v3.4 어휘 가이드 준수:
  - **일반국민**: 법 전문용어 사용 시 괄호 안 설명
  - **기업 컴플라이언스 담당자**: 조문·요건 직접 인용 + 사전 예방 포인트 + "당사/자사" 시점
  - **논문 준비 학생**: 법령 조문 직접 인용 + 비례성·선례·판례·함의 + 후속 연구 과제

## 원칙 3 — 페르소나 × 난이도 직교
- 페르소나는 어휘·톤
- 난이도는 깊이·전문성
- "일반국민 + 전문가(난이도)" = 쉬운 어투 + 깊은 내용

## 원칙 4 — 추측 금지
- 의결서 원문 + Step 1·2·3·4 결과만 사용
- "유사사례"·"통계기반"이라도 다른 사건의 구체 정보 창작 ❌
- 일반론 OK
- 모르는 값: `"공개된 정보로는 확인 어려움"` 명시

## 원칙 5 — 각 Q&A에 chunk_id 1개 이상 박음 강제 (v2)
- 각 Q&A의 `근거_short`는 Step 4 evidence의 chunk_id 1개 이상
- 형식: `{사건키}_{3자리} (Header § Header2)` 또는 `{사건키}_{3자리} [section]`
- 질문유형별 매핑:
  - 제재중심 → `evidence.sanction_evidence.*`
  - 법령중심 → `evidence.legal_evidence.*`
  - 유사사례 → `evidence.facts_evidence.행위` 또는 `key_evidence`
  - 통계기반 → `evidence.facts_evidence.결과` 또는 `key_evidence`
  - 시장영향 → `evidence.facts_evidence.시장` 또는 `key_evidence`
- 매칭 chunk 없으면 `evidence.key_evidence.chunk_id` fallback (그래도 1개는 박음)

## 원칙 6 — 길이 준수
- 페르소나·난이도 매트릭스 길이 범위 내

## 원칙 7 — JSON 스키마 강제
- 출력은 JSON 배열 (45개 객체)
- 키 누락·추가 ❌
- 빈 문자열 ❌

# Few-shot 예시 (3건 — 에스피피조선, 페르소나별 1개)

각 페르소나가 **다른 질문유형 × 다른 난이도 조합**을 가지도록 시현.

## 예시 1 — 일반국민 / 제재중심 / 기초

```json
{
  "페르소나": "일반국민",
  "질문유형": "제재중심",
  "난이도": "기초",
  "질문": "에스피피조선이 받은 처벌이 뭐예요?",
  "답변": "공정거래위원회가 에스피피조선에게 시정명령(다시는 그러지 말라는 명령)하고 과징금(벌금 같은 거예요) 4억 8천만 원을 부과했어요. 이 회사가 12개 협력업체한테 단가를 마음대로 7~15% 깎아서 4억 8,300만 원이나 덜 줬거든요.",
  "근거_short": "에스피피조선_002 [주문]"
}
```

박음 포인트:
- 일반국민 어휘: "마음대로 깎아서", "벌금 같은 거예요" (생활 밀착 비유)
- ⭐ **법 전문용어 사용 시 괄호 안 설명**: "시정명령(다시는 그러지 말라는 명령)", "과징금(벌금 같은 거예요)"
- 톤 마커: `~요`·`~거든요`
- 길이: ~135자 (일반국민·기초 80~150자)
- 근거_short: sanction_evidence.과징금액의 chunk

## 예시 2 — 기업 컴플라이언스 담당자 / 법령중심 / 심화 ⭐ (v3.4 정렬)

```json
{
  "페르소나": "기업 컴플라이언스 담당자",
  "질문유형": "법령중심",

# 예외 처리

## 케이스 1 — 통계기반 질문에 직접 데이터 부족
- 본 의결서 1건만으로 통계 답변 어려움
- **본 사건의 수치 + 사건유형의 통상적 패턴**으로 구성
- 다른 사건의 구체 수치 창작 ❌

## 케이스 2 — 유사사례 질문에 비교 사건 부족
- **본 사건의 핵심 행위 + 같은 사건유형의 공통 요소**로 구성
- 특정 사건명·금액 창작 ❌

## 케이스 3 — 시장영향 질문에 시장 정보 부족
- `facts.시장` = `"정보 없음"`인 경우
- 사건유형 + 산업 분야 일반론으로 답변
- "공개된 정보로는 정확한 시장 영향 평가 어려움" 명시 OK

## 케이스 4 — 페르소나·난이도 길이 충돌
- 일반국민 페르소나 + 전문가 난이도에서 깊은 내용 + 80~400자 길이 충돌 시
- **길이 우선 + 깊이 일부 압축**
- 톤 유지가 최우선

## 케이스 5 — 근거_short 매칭 chunk 없음
- 질문유형별 매핑 chunk가 evidence에 없을 시
- `evidence.key_evidence.chunk_id` fallback 사용 (반드시 1개는 박음)
- 그래도 없으면 Step 4 evidence 재검토 필요

## 케이스 6 — 사건유형이 답변하기 어려운 경우
- 의결서 정보 매우 빈약 (단순 경고 1쪽 등)
- 답변에 "공개된 의결서 정보로는 ~ 어려움" 솔직하게 명시
````
