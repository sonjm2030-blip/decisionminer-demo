# DecisionMiner 기획서 — 2장 데이터 활용

> **본 장의 핵심**: DecisionMiner는 의결서 1건을 5단계로 분해하여 5종 표준 데이터셋을 동시 산출한다. 페르소나·질문유형·난이도 3축 매트릭스로 체계적 다양성을 확보하며, 단일 RAG 챗봇이 아닌 다양한 AI 서비스 구축에 재사용 가능한 학습 자산을 만든다.

---

## 2.1 5단 분해 흐름

DecisionMiner는 공정거래위원회 공개 의결서를 5단계로 자동 분해한다. 각 단계는 독립된 프롬프트로 작동하며, 단계별 출력이 다음 단계의 입력으로 연결되는 파이프라인 구조다. **한 번의 분해 실행이 5종 표준 데이터셋을 동시에 산출하는 효율적 설계**가 본 도구의 핵심이다.

![5단 분해와 5종 데이터셋 동시 산출 흐름](visuals/5단_5종_흐름.png)

### Step별 산출물과 데이터셋 매핑

| Step | 작업 | 산출 메타 | 연결 데이터셋 |
|---|---|---|---|
| **Step 1 사실관계** | 5요소 추출 (주체·상대방·시장·행위·결과) | `summary_short`, `facts_structured` | 요약, 사실관계 |
| **Step 2 위반법리** | 4단계 추론 + 5항목 분류 | `inference_chain`, `classification_tags` | 분류, 추론 |
| **Step 3 처분** | 시정명령·과징금·고발 정리 | `sanction.json` | (간접 활용) |
| **Step 4 페르소나** | 3 × 5 × 3 = 45 Q&A 생성 | 990건 Q&A | QA |
| **Step 5 근거 매핑** | 답변→의결서 chunk 출처 보존 | `evidence.json` | (모든 데이터셋 공통 근거) |

### 핵심 원리 — 5단 1번 실행 = 5종 데이터셋 동시 산출

전통적인 학습데이터 구축에서는 데이터셋 종류마다 별도 추출 작업이 필요하다. DecisionMiner는 **5단 v2 프롬프트 1회 실행으로 5종 데이터셋(QA·요약·사실관계·분류·추론)이 부산물로 동시 산출**된다. 의결서 1건당 약 50회의 AI 호출만으로 5종 시트 전체가 채워진다.

22건 의결서에 대한 실측 결과:

| 항목 | 값 |
|---|---|
| 처리 시간 | 약 4시간 (실 batch 시간) |
| API 비용 | $27.81 |
| 산출 Q&A | 990건 |
| 산출 메타 (4종) | 22 × 4 = 88행 |
| 합산 데이터 | **1,078행** |
| 실패율 | 0% (JSON 복구·캐시 안정 작동) |

Step 1·2의 메타 추출은 단순한 부수 산출이 아니라 **데이터셋 다양성 확보의 핵심**이다. 같은 의결서에서 요약·사실관계·분류·추론이라는 4가지 다른 형식의 데이터를 추가 비용 없이 얻는 구조다.

## 2.2 5종 데이터셋 표준

DecisionMiner의 차별성은 단일 형태 학습데이터가 아닌 **5종 표준 데이터셋**을 동시에 제공하는 점이다. 각 데이터셋은 다른 AI 서비스 구축의 출발점이 된다.

### 5종 정의와 활용처

| # | 데이터셋 | 정의 | 활용처 |
|---|---|---|---|
| 1 | **QA** | 페르소나·질문유형·난이도 3축 Q&A 쌍 | 챗봇·QA 시스템·검색 응답 |
| 2 | **요약** | 의결서 핵심을 3~5문장으로 압축 | 뉴스 요약·시민 안내·검색 결과 카드 |
| 3 | **사실관계** | 5요소 구조화 (주체·상대방·시장·행위·결과) | 사건 검색·사실 추출 모델 학습 |
| 4 | **분류** | 사건유형·법령·조문·처분·산업 5항목 라벨 | 자동 분류 모델·태그 추천 |
| 5 | **추론** | 위반 판단의 4단계 논증 체인 | 법리 추론 모델·논증 학습 |

### 분량과 합산 통과

| 데이터셋 | 행 수 | 비고 |
|---|---|---|
| QA | 990 (Day 8 컷 후 600~660) | 페르소나 균등 |
| 요약 | 22 | 의결서당 1행 |
| 사실관계 | 22 | 5요소 분리 시 110행 가능 |
| 분류 | 22 | 5항목 분리 시 110행 가능 |
| 추론 | 22 | 4단계 분리 시 88행 가능 |
| **합산** | **1,078** | 500건 합산 기준 **1.5배 초과** ✓ |

공모 분량 기준(500건 합산)을 1.5배 초과 달성한다. 개별 데이터셋은 22~990행이지만 5종 합산으로 충분한 분량을 확보한다.

### 차별성 — "공정위 의결서를 5종 표준 데이터셋으로 변환하는 첫 시도"

기존 공공 AI 데이터셋은 단일 형태 위주다(예: 챗봇용 QA만, 분류용 라벨만). DecisionMiner는 **5단 분해 파이프라인 1회 실행으로 5종 표준 데이터셋이 자동 산출**되는 구조를 박았다. 이는:

- **표준화**: 5단 v2 프롬프트가 곧 산출 명세 — 누가 실행해도 동일 스키마
- **자동 산출**: 5종이 부산물로 동시 생성 — 추가 작업 불필요
- **재사용성**: 1개 의결서 처리로 5가지 AI 서비스 데이터 확보

이는 공정거래 분야 학습데이터 구축의 새로운 표준 모델을 제시한다.

## 2.3 Persona-Question Matrix

DecisionMiner의 QA 데이터셋은 **3축 균등 분배**로 체계적 다양성을 확보한다.

![Persona × Question × Difficulty Matrix](visuals/persona_question_matrix.png)

### 3축 구조

| 축 | 값 | 분포 (990건 합산) |
|---|---|---|
| **페르소나** (3) | 일반국민 / 기업 컴플 / 논문 학생 | 각 330건 |
| **질문유형** (5) | 제재중심 / 법령중심 / 유사사례 / 통계기반 / 시장영향 | 각 198건 |
| **난이도** (3) | 기초 / 중급 / 심화 | 각 330건 |

### 조합 산출

3 × 5 × 3 = **45조합 / 의결서 1건**. 22 의결서 × 45 = **990 Q&A**.

각 조합은 의결서 안에서 다른 관점·다른 깊이의 Q&A를 생성한다. 예: 같은 의결서를 일반국민 페르소나는 "쿠팡이 받은 처벌은?" 식으로 묻고, 논문 학생 페르소나는 "본 의결서의 시장지배력 남용 판단 기준은?" 식으로 묻는다.

### 차별점 — 체계적 다양성

| 측면 | 일반 학습데이터 | DecisionMiner |
|---|---|---|
| 사용자 관점 | 단일 (대개 전문가) | **3가지 페르소나** |
| 질문 다양성 | 임의 | **5종 균등 분배** |
| 난이도 | 단일 | **3단계 균등 분배** |
| 활용 가치 | 단일 AI 서비스 | **3가지 AI 서비스 동시** |

이 매트릭스 구조는 **하나의 의결서에서 시민 교육·기업 컴플라이언스·학술 연구라는 3가지 다른 AI 서비스 데이터를 동시에 확보**한다는 것을 의미한다.
