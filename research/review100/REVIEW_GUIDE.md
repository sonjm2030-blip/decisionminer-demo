# DecisionMiner 법률 전문가 재검수 지침

초안 v0.1 · 2026-11-01. 검수자와 기준을 합의한 후 확정합니다. 아직 새 검수 결과는 없습니다.

## 검수 범위와 순서

공모전 최종 제출본 중 기존 검수와 같은 100개 ID를 다시 검수합니다. 질문·답변·제공된 근거 발췌를 확인하고, 함께 제공한 공개 의결서 원문으로 판정합니다. 근거 발췌 자체도 검증 대상입니다. 법령은 사건 당시 적용 조문과 시행 시점을 기준으로 확인하며, 외부 자료를 확인했다면 문서명·링크·확인일을 기록합니다.

1. 압축을 풀고 `문항자료.html`을 엽니다. 문항 번호 R001~R100으로 이동하고 원문 PDF를 확인합니다.
2. `검수표.xlsx`의 `검수입력`에서 동일 번호의 행을 작성합니다. 긴 질문·답변·근거는 HTML에서 전체를 읽습니다.
3. 5개 세부 항목, 종합 판정, 근거 위치, 판정 사유, 확신도, 검수자코드, 검수일을 작성합니다. 보정필요·부적합은 보정안 또는 수정 방향도 기록합니다. 소요시간(분)은 실제 측정한 경우만 입력합니다.
4. 검수자정보 양식을 별도로 작성합니다. 이름 대신 검수자코드를 쓰고, 자격·전공·관련 경력 및 기존 프로젝트 참여 여부를 명시합니다. 이 양식과 작성한 검수표는 비공개로 반환합니다.

종합 판정은 사람이 내립니다. 입력 확인 표시는 작성 항목 점검이며 법률적 타당성 검증을 뜻하지 않습니다. 이전 판정·자동 판정·기존 보정안은 참고하지 않습니다. 공개 저장소에 과거 결과가 있으므로 이번 파일 제공 범위에서의 눈가림이며, 기존 참여·사전 노출 여부를 신고합니다.

## 세부 항목

각 항목은 `문제없음 / 경미오류 / 중대오류 / 판단불가 / 해당없음` 중 선택합니다.

| 항목 | 확인 내용 |
| --- | --- |
| 사실 | 당사자·행위·기간·시장·사건 사실이 원문과 일치하는가 |
| 법령 | 법령명·조문·시점·적용 대상이 맞고, 다른 법률을 혼동하지 않는가 |
| 논증 | 위반 요건과 사실의 연결, 결론의 범위가 타당한가. 사건 결론을 일반 법칙으로 과장하지 않는가 |
| 제재·수치 | 과징금·과태료·시정명령 등 제재 종류, 금액·단위·수치가 맞는가 |
| 근거 | 답변의 핵심 주장을 원문이 뒷받침하는가. 인용·발췌가 문맥을 왜곡하거나 뒷받침하지 못하는가 |

`경미오류`: 핵심 법률 결론·권리의무·제재를 바꾸지 않는 표현 또는 부수 정보 문제.
`중대오류`: 적용 법률·위반 요건·권리의무·제재·핵심 사실 등 결론에 영향을 주는 오류.
`판단불가`: 필요한 자료 부족 또는 검수 범위를 벗어나 결론을 정할 수 없음.
`해당없음`: 문항이 그 항목을 다루지 않음. 사유 칸에 적용하지 않은 이유를 적습니다.

단순 문체 취향은 법률 오류로 처리하지 않습니다. 쉬운 설명이 법적 의미를 바꾸는 경우에는 오류로 기록합니다. 하나의 오류가 여러 항목에 걸칠 수 있으며 중복 유형은 사유에 구분합니다.

## 종합 판정

| 판정 | 기준 |
| --- | --- |
| 적합 | 질문에 답하고 핵심 주장이 근거로 확인되며, 수정이 필요한 오류가 없음 |
| 보정필요 | 핵심 결론을 유지한 채 한정적인 수정으로 사용할 수 있음. 수정 위치와 안을 제시 |
| 부적합 | 핵심 사실·법령·논증·제재 오류 등으로 답변의 주요 내용을 다시 작성해야 함 |
| 판단보류 | 자료 부족·전문 범위 한계 등으로 종합 결론을 내릴 수 없음. 부족한 자료와 이유를 제시 |

세부 중대오류가 있어도 국소 수정으로 해결된다고 판단하면 보정필요를 선택할 수 있으나 그 이유를 명시합니다. 핵심 주장이 검증되지 않으면 적합으로 처리하지 않습니다. 판단보류를 오답으로 자동 변환하지 않습니다. 확신도는 `높음 / 보통 / 낮음`이며 정답률을 의미하지 않습니다.

근거 위치 예: `C05.pdf 뷰어 8쪽 / 본문 7쪽, 23문단`. PDF 쪽수와 본문 쪽수가 다르면 둘 다 적습니다. 판단보류는 확인한 범위와 추가로 필요한 자료를 적습니다.

## 기준 확정과 결과 보존

먼저 같은 100건 중 5건으로 지침의 모호한 부분을 점검합니다. 기준이 바뀌면 버전을 올리고 최초 5건도 새 기준으로 재검수합니다. 기존 답변을 검수 중 덮어쓰지 않고 보정안에 따로 기록합니다. 최종 판정 이전의 의견도 원본으로 보존합니다.

가능하면 별도 합의한 동일 20건을 두 번째 검수자가 독립 검수하고 불일치 사유와 합의 결과를 기록합니다. 추가 인력·비용은 아직 확정되지 않았으며 100개 고유 문항의 범위를 자동 확대하지 않습니다.

이 100건은 기존 교정 표본을 재검수하는 용도입니다. 전체 990건의 무작위 대표 표본 또는 독립 시험세트로 해석하지 않습니다. 향후 최종 성능 평가는 개선에 쓰지 않은 사건 단위 분리 표본으로 별도 설계합니다.
