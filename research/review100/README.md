# 기존 100건 전문가 재검수 준비

상태: 검수 준비. 새 전문가 판정·검수자 자격 확인·모델 실험·외부 의뢰는 아직 수행하지 않았습니다.

진행 우선순위: 사용자 요청으로 재검수 세팅은 현 상태로 보존합니다. 현재 작업은 [기존 검수 기록을 이용한 사후 분석](../legacy_review/README.md)이며 추가 재검수 준비나 의뢰는 진행하지 않습니다.

기준은 `74135ad`의 공모전 최종 제출본이며 main과 `baseline/competition-2026-11-01`은 보존합니다. 기존 100개 ID를 그대로 선택하고, 최종본의 질문·답변·근거를 대상으로 검수합니다. 최종본의 자동판정·기존 검수 결과·보정안은 검수용 파일에 넣지 않습니다. 답변 끝의 정확한 보정 이력 안내 문구만 제거하고, 문자열의 `\n`을 화면 줄바꿈으로 변환합니다. 본문을 새로 교정하지 않습니다.

## 버전 감사

재현 가능한 결과는 `target_manifest.json`에 있습니다. NFC 정규화와 양끝 공백 제거 후 문자열을 비교했습니다. 답변 68건이 다르며, 보정 이력 안내 문구를 제외한 차이는 21건입니다. 질문은 20건이 다릅니다. 이는 텍스트 차이이며 의미·법률 오류의 수가 아닙니다. 원본 검수표에는 최종본과 동일 정의의 근거 열이 없어 전체 입력 동등성도 확인되지 않았습니다.

따라서 기존 사람 판정과 최종 정적 라벨을 연결한 98/100 등은 버전이 다른 자료의 ID 기준 교차표입니다. 동일 입력에 대한 검수 타당성·성능 향상으로 해석하지 않습니다. 기준 버전의 기록은 보존하고 이 후속 발견을 함께 제공합니다.

100건은 22개 사건에 걸쳐 사건당 2~6건입니다. 기존 설명의 3~6건과 다릅니다. 재표집으로 맞추지 않고 실제 분포를 기록했습니다. 이 표본은 기준 보정에 사용되었으므로 새 전문가 재검수 이후에도 독립 시험세트가 되지 않습니다.

## 참고 논문과 이번 설계에 반영한 점

- [Developing a Pragmatic Benchmark for Assessing Korean Legal Language Understanding in Large Language Models (KBL, 2024)](https://aclanthology.org/2024.findings-emnlp.319/): 법률 지식·추론과 전문가 참여를 구분한 평가 설계를 참고했습니다. 검수자의 전공·자격·관련 경력과 역할을 별도 기록합니다.
- [Korean Canonical Legal Benchmark (KCL)](https://arxiv.org/abs/2512.24572): 문항별 근거와 세부 평가 기준을 연결하는 접근을 참고했습니다. 사실·법령·논증·제재·근거를 구분하고 페이지 위치를 기록합니다.
- [CoAnnotating (EMNLP 2023)](https://aclanthology.org/2023.emnlp-main.92/): 사람·LLM의 검수 자원 배분을 후속 연구 주제로 참고합니다. 이번에는 판단보류·확신도·실제 소요시간을 기록할 수 있게 했습니다. 논문의 알고리즘을 구현하거나 성과를 재현한 것은 아닙니다.

위 논문들은 설계 참고 문헌이며 이번 100건이 해당 벤치마크의 프로토콜이나 검증 수준을 충족한다는 뜻은 아닙니다. 실제 판단 기준은 [검수 지침](REVIEW_GUIDE.md) 초안에 있습니다. 검수자와 합의 후 버전을 확정합니다.

## 재현

Python의 `openpyxl`, `pypdf`가 필요합니다. 원문은 공정위 공개 의결서 22건이며 저장소 밖의 원문 폴더를 명시합니다. 준비 코드는 원본 XLSX 해시와 100개 ID 및 22건 PDF 연결을 검사합니다. 파일명이 잘린 3건은 원문 첫 페이지의 사건명·의결번호를 확인해 명시적으로 연결했습니다.

```sh
python -m pip install -r research/review100/requirements.txt
python research/review100/prepare_packet.py --pdf-root '/path/to/public-decisions' --out '/path/to/reviewer-packet'
```

문항자료 HTML과 원문 사본은 지정한 폴더에 생성됩니다. `--render-input` 옵션으로 렌더링용 JSON의 별도 경로를 지정할 수 있습니다. 검수표 XLSX는 같은 데이터로 별도 작성합니다. 작성된 검수표와 개인정보 양식은 공개 저장소에 커밋하지 않습니다.

## 이후 분석

새 판정이 수집되면 동일한 고정 입력·표본·정의를 사용해 규칙 기준점과 비교합니다. 판단보류 비율을 별도 보고하고 제외 시 분모를 명시합니다. 3범주 비교에서는 `적합→적합, 검토→보정필요, 부적합→부적합`이라는 분석용 대응을 사전 고정하되, 규칙 경고와 법률 판정의 의미가 같다는 주장은 하지 않습니다. 혼동행렬·범주별 일치도·엄격 일치도 및 가능한 경우 κ를 함께 보고합니다. 100건 개선 결과는 교정 표본 결과로 표시하고, 전체 성능은 사건 단위로 분리한 독립 평가에서 확인합니다.
