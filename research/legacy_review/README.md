# 기존 검수 기록을 이용한 DecisionMiner 분석

2026-11-01 · 기존 교정 표본의 사후 분석. 신규 법률 판정·LLM 호출·학습·외부 의뢰는 수행하지 않았습니다. 전문가 재검수 준비물은 현 상태로 보존하고, 기존 기록으로 가능한 분석을 먼저 진행했습니다.

현재 자료로 확인되는 문제는 **규칙을 통과한 답변에도 법률 검수자가 보정을 요구한 사례가 많다**는 것입니다. 이를 토대로 연구 A는 규칙 경고와 법률 판정의 불일치, 연구 B는 제한된 검수 건수에서 어떤 문항을 먼저 볼 것인지로 구체화할 수 있습니다. 아래 결과는 개선에 이미 쓰인 작은 표본의 진단이며 외부 성능 평가가 아닙니다.

## 1. 기존 기록에서 확보한 것

| 항목 | 결과 |
| --- | ---: |
| 기존 검수 기록 | 100건, 22개 사건 |
| 기존 판정 OK | 37건 |
| 기존 판정 보정 필요 | 61건 |
| 기존 판정 환각 | 2건 |
| 보정안이 있는 기록 | 66건 |
| 메모가 있는 기록 | 67건 |
| 원본 신뢰도 누락 | 1건 |

위 판정은 원본 검수자의 기록을 그대로 사용했습니다. ‘환각’ 2건은 이번에 새로 판정한 사실성 오류 수가 아닙니다. 원본의 신뢰도는 1~4 값이 기록돼 있으나 이를 정답 확률로 해석하지 않았습니다. 검수자의 변호사 자격·법률 전문성이나 검수자 간 일치도는 현재 자료로 새롭게 확인하지 않았습니다.

기존 `qa_corrections_100.csv`의 63행은 보정 필요 61건과 환각 2건으로, 원본 보정안·메모와 모두 일치합니다. 원본에는 OK 판정에도 보완안이 있는 3건(남양 2건, 신세계 1건)이 더 있습니다. 따라서 **보정안 유무와 기존 판정은 서로 다른 정보**입니다.

분석용 [100건 원본 기록·계보 표](existing_review100.csv)에 기존 열을 보존하고, 대응 ID·공통 항목 일치 여부·중복 보정안 표시를 추가했습니다. 신규 법률 라벨은 만들지 않았습니다.

## 2. 보정안에서도 발견한 품질 문제

`QA-롯데-002`와 `QA-에스피피-002`의 보정안이 완전히 같습니다. 에스피피 문항은 하도급법을 묻는데 보정안에는 롯데쇼핑, 대규모소매업고시와 종업원 파견 약정이 등장합니다. 같은 내용이 메모에도 이어집니다. 이는 다른 사건의 보정안이 섞였을 가능성을 보여줍니다.

원본을 고치거나 어느 답변이 법적으로 맞다고 새로 확정하지 않았습니다. 보정안을 이용하는 후속 작업에서는 **동일문장인 두 기록을 모두 보류**했습니다. 보정 필요·환각 63건에서 이 두 건을 제외한 [제안 답변 쌍 61건](proposed_correction_pairs61.csv)을 따로 정리했습니다. 이 파일은 미재검증 후보이며 학습용 정답·선호쌍으로 확정한 데이터가 아닙니다. OK의 보완안 3건도 오답→정답 쌍으로 합치지 않았습니다.

## 3. 100건 중 79건으로 규칙을 다시 실행한 이유

검수 원본과 기준 master CSV의 ID 대응을 만든 뒤, 페르소나·사건유형·적용법령·적용조문·질문·답변의 **공통 6항목이 모두 일치하는 79건**을 선정했습니다. 문자열 비교는 NFC 정규화와 양끝 공백 제거 기준입니다.

나머지 21건은 질문 또는 답변이 다르므로 주 비교에서 제외했습니다. 이 차이가 모두 사후 수정 때문인지, 일부 ID 대응 문제인지까지 단정하지 않습니다. 기존 검수 원본의 질문·답변은 분석 자료에 그대로 남겼습니다. 제외 ID와 상이 항목도 공개했습니다.

제외한 21건도 기존 검수·보정 과정에 쓰인 기록이므로, 독립 시험세트로 전환하지 않습니다.

79건의 원본 판정은 OK 32건, 보정 필요 46건, 환각 1건입니다. 근거 발췌·질문유형·난이도는 기준 master에서 복원했습니다. 원본 검수표에는 동일 정의의 열이 없으므로 **과거 검수 당시 전체 맥락까지 같다는 보장은 없습니다**. 재실행 입력의 해시를 문항별로 저장했습니다.

재실행은 기존 `quality_checker_grounding.py`의 두 모드를 사용했습니다. 이는 과거 CSV 결과를 재현하는 실행이 아니라, 기준 코드의 진단 모드를 같은 입력에 실행한 것입니다.

- **텍스트 조문 확인**: 근거 발췌에 조문·법령 표현이 없으면 차단하는 `grounding=False`.
- **구조화 조문 확인**: 별도 법령·조문 필드도 확인에 사용하는 `grounding=True`.
- **모두 검토**: 입력에 관계없이 검토를 출력하는 단순 기준점.

예측 입력에는 기존 사람 판정·신뢰도·메모·보정안·최종 정적 라벨을 넣지 않았습니다. 별도 보정안 반응 검사에서만 원답변을 검수자의 제안 답변으로 바꿨습니다. 규칙·임계값·생산 데이터는 수정하지 않았습니다.

## 4. 79건에서의 실행 결과

사람 판정을 분석용으로 `OK→적합, 보정 필요→검토, 환각→부적합`에 대응시켰습니다. 규칙 경고와 법률 판정의 의미가 같다는 가정은 아닙니다. 정확 일치는 세 범주가 같은 비율이고, 균형 정확도는 사람 범주별 재현율의 평균입니다.

| 방법 | 세 범주 일치 | 균형 정확도 | Macro F1 | Cohen's κ |
| --- | ---: | ---: | ---: | ---: |
| 모두 검토 | 46/79 (58.2%) | 33.3% | 0.245 | 0.000 |
| 텍스트 조문 확인 | 16/79 (20.3%) | 14.8% | 0.201 | 0.020 |
| 구조화 조문 확인 | 43/79 (54.4%) | 37.5% | 0.365 | 0.114 |

구조화 조문 확인 모드는 텍스트 확인의 과도한 차단을 줄입니다. 그러나 세 범주 일치율은 ‘모두 검토’보다 낮습니다. 균형 정확도와 F1에서는 단순 기준점보다 높지만, 법률 품질 판단이 충분해졌다는 근거는 아닙니다. 작은 교정 표본에서의 변화이며 유의성·일반화 성능은 검증하지 않았습니다.

구조화 모드의 혼동행렬은 다음과 같습니다. 행은 기존 사람 판정, 열은 이번 규칙 출력입니다.

| 기존 사람 판정 | 규칙 적합 | 규칙 검토 | 규칙 부적합 |
| --- | ---: | ---: | ---: |
| OK | 20 | 12 | 0 |
| 보정 필요 | 23 | 23 | 0 |
| 환각 | 0 | 1 | 0 |

검수자가 보정을 요구한 46건 중 **23건을 규칙이 적합으로 통과**시켰습니다. 보정 필요·환각을 합한 검토 대상 47건 중, 규칙의 검토·부적합 출력으로 확인 대상으로 보낸 것은 24건(51.1%)입니다. 규칙이 적합으로 통과시킨 43건 안에는 기존 보정 필요 23건이 있습니다. 이때 사람 판정은 답변뿐 아니라 조문 열 등의 문제도 포함할 수 있습니다.

다음은 그 23건 중 기존 메모에 기록된 문제의 예입니다. 유형은 메모 내용을 묶은 분석용 설명이며, 이번에 원문으로 다시 법률 판정을 내린 결과가 아닙니다.

| 문항 ID | 기존 메모가 지적한 문제 | 규칙으로 확인하기 어려운 부분 |
| --- | --- | --- |
| QA-글락소-030 | 제19조 제1항 제4호·제9호와 설명의 연결 부족 | 조문 필드의 존재와 조문의 정확성·완전성은 다름 |
| QA-쿠팡-002 | 소비자 유인·거래의 기만성을 ‘물건·서비스 판매 금지’처럼 설명 | 법령명이 있어도 위반 취지의 의미가 달라질 수 있음 |
| QA-엘지생건-045 | 시장 실패·피해 구제 등 의결서 범위를 넘어서는 평가 | 추측 표현이 없어도 근거를 벗어난 주장이 가능 |
| QA-경북택시-041 | 시정명령 외 구성사업자 통지명령도 반영 필요 | 제재 단어의 존재가 처분 전체의 정확한 설명을 보장하지 않음 |
| QA-금호아시아나-030 | 항공운송시장보다 터미널·버스운송시장 및 경제력 집중 효과로 설명 보완 | 시장 관련 단어의 일치만으로 논증 대상의 적절성을 확인하기 어려움 |

‘적합+검토’를 사용가능으로 합치면 일치는 78/79(98.7%)로 높아집니다. 이 표본에서 **아무 문항도 부적합으로 내보내지 않는 단순 출력도 같은 수치**를 얻습니다. 희소한 환각 1건의 구분과 보정 필요 탐지를 함께 보지 않으면 98.7%가 무엇을 의미하는지 판단하기 어렵습니다. 이 수치는 기존 100건의 역사적 99%·최종 라벨 98%와 표본·출처가 다릅니다.

원문항별 결과는 [규칙 재실행 79건](rule_replay79.csv), 전체 계산·입력 해시는 [metrics.json](metrics.json)에 있습니다.

## 5. 보정안에 규칙이 어떻게 반응하는가

79건 중 기존 제안 답변이 있는 47건에서 답변만 교체해 구조화 모드를 다시 실행했습니다. 적용조문 등 다른 필드를 함께 교정하지 않았으며, 제안 답변의 정확성을 새로 검증하지도 않았습니다.

| 원답변 출력 → 제안 답변 출력 | 건수 |
| --- | ---: |
| 검토 → 적합 | 2 |
| 적합 → 검토 | 15 |
| 검토 → 검토 | 22 |
| 적합 → 적합 | 7 |
| 적합 → 부적합 | 1 |

이 표는 보정의 성공·실패율이 아닙니다. 표현·길이·조문·추측 표현에 반응하는 규칙과 법률적 보정이 일관되게 움직이지 않는다는 진단입니다. 제안 답변이 확정 정답이라고 가정해 규칙을 무조건 통과하도록 조정하면 안 됩니다.

## 6. 검수 순서에 관한 사후 탐색

구조화 모드의 범주 심각도, 차단 수, 경고 수 순으로 정렬해 제한된 건수를 먼저 본다고 가정했습니다. 동점 안에서는 무작위로 선택한다고 보고 기대 발견 건수를 정확히 계산했습니다. 사람의 판정·신뢰도·메모·보정안은 순서 결정에 사용하지 않았습니다. 이 정렬은 사후 탐색이며 사전 등록한 실험이 아닙니다.

| 먼저 보는 문항 수 | 규칙 순서의 보정 필요·환각 발견 기대 건수 | 무작위 기대 건수 | 동점 선택에 따른 규칙 순서의 가능 범위 |
| --- | ---: | ---: | ---: |
| 10 | 9.56 | 5.95 | 9~10 |
| 20 | 15.11 | 11.90 | 9~20 |
| 40 | 26.14 | 23.80 | 24~28 |
| 60 | 36.84 | 35.70 | 28~47 |

앞부분 일부를 우선 확인하는 용도는 탐색할 가치가 있습니다. 다만 문항별 비용이 같다는 건수 대용치이고, 검수 시간·인건비·LLM 비용·다운스트림 학습 성능을 측정하지 않았습니다. 따라서 비용 절감이나 CoAnnotating 재현 성과로 보고하지 않습니다. 문항들은 사건별로 묶여 있고, 기존 선별 표본이므로 990건 전체의 발견률로 확대할 수 없습니다.

## 7. 기존 논문 본문의 방법과 대조

이번에는 초록 확인에 그치지 않고 아래 절의 본문을 확인했습니다. 논문 수치를 DecisionMiner 수치와 같은 조건의 성능 순위로 비교하지 않았습니다. 읽은 절·PDF 해시는 [문헌 확인 기록](paper_sources.json)에 남겼습니다.

| 논문과 확인 범위 | 논문의 방법에서 확인한 점 | DecisionMiner의 차이와 이번 적용 |
| --- | --- | --- |
| [KBL](https://aclanthology.org/2024.findings-emnlp.319.pdf), §3.1·3.2·4.1·4.2, PDF 3~7쪽 | 법률 지식·추론을 별도 과제로 평가. COMP는 검수·수정 뒤 다시 확인하며, 평가에는 단순 최빈 선택 기준점도 제시 | 기존 보정안을 확정 정답으로 간주하지 않음. 원본·제안 답변을 나눠 보존하고 단순 ‘모두 검토’ 기준점과 비교. 객관식 과제의 점수와 자유응답 품질 판정은 직접 비교하지 않음 |
| [LegalBench](https://arxiv.org/pdf/2308.11462), §3·4·5.1.3, PDF 6~10·13쪽 | 법률 추론 유형을 구분하고, 불균형 분류에 균형 정확도를 사용. 설명형 법 적용에는 별도 사람 평가 | 페르소나·질문유형 5종을 법률 추론 유형과 동일시하지 않음. 범주별 혼동행렬·균형 정확도를 추가하고 규칙 경고를 법 적용 정답률로 부르지 않음 |
| [KCL](https://arxiv.org/pdf/2512.24572), §2·3·Appendix A.1, PDF 2~3·9쪽 | 문항별 뒷받침 판례와 세부 채점 기준을 연결. LLM Judge를 별도 법률가 평가와 대조 | 현재 메모는 세부 기준을 만드는 소재이며 검증된 루브릭이 아님. 이번에는 LLM Judge를 실행하지 않음. 연속 채점 점수의 Pearson 상관과 이번 범주 κ를 직접 비교하지 않음 |
| [CoAnnotating](https://aclanthology.org/2023.emnlp-main.92.pdf), §3·4.3, PDF 3~6쪽 | 여러 프롬프트의 예측 불확실성으로 사람·LLM에 배분하고, 분류기 시험 성능과 금전 비용을 평가 | 기존 규칙 경고로 검수 순서만 탐색. 사람의 사후 신뢰도를 모델 불확실성으로 사용하지 않음. 엔트로피·실제 비용·학습 효용이 없어 논문 방법 재현으로 주장하지 않음 |

이 대조에서 얻는 연구 방향은 ‘공정위 데이터가 있으므로 새 벤치마크’라는 주장보다 **규칙 검사와 법률적 품질 판정 사이의 차이를 보여 주고, 검수 기록이 그 차이를 줄이는 데 어떤 역할을 하는지 검증하는 것**입니다. 이는 이번 자료에 대한 해석이며 신규성의 확정 판정은 아닙니다.

## 8. 기존 기록으로 이어갈 연구 두 가지

**연구 A: 규칙 검사로 통과한 문항에서 법률적 보정이 필요한 이유는 무엇인가?** 이번에는 원본 메모를 근거로 실패 사례를 수집하고 세 범주 평가를 재현했습니다. 예를 들어 글락소 조문 누락, 금호 지원행위별 제재 구분, 논문 준비 학생 답변의 근거 밖 정책 평가처럼 서로 다른 문제가 있습니다. 다음에는 메모를 이용한 잠정 루브릭을 개발용 자료로 만들 수 있습니다. 같은 기록으로 루브릭을 만들고 평가하면 개발 결과이며 독립 검증이 아닙니다.

**연구 B: 적은 검수 건수로 보정 대상 문항을 먼저 찾을 수 있는가?** 이번에는 규칙 경고 순서와 무작위 순서의 내부 발견 기대 건수를 계산했습니다. 이후 LLM 불일치·불확실성 같은 신호를 추가한다면, 같은 입력·예산 정의로 비교하고 실제 시간·비용을 따로 기록해야 합니다. 현재의 발견 기대 건수로 비용 절감을 주장하지 않습니다.

현재 단계에서 사용할 수 있는 표현은 ‘기존 100건 검수 기록을 정리하고, 입력 일치 79건에서 규칙 기반 검수의 한계와 검수 우선순위를 사후 분석했다’입니다. ‘전문가 재검수 완료’, ‘법률 정답률 99%’, ‘보정안 61건의 정확성 검증’, ‘논문 기법 재현 완료’라는 표현은 현재 작업에 해당하지 않습니다.
